Cole aqui a sua chave de acesso para gerenciar os produtos do site.

Não tenho a chave — como criar?
  1. Abra esta página do GitHub (faça login se pedir).
  2. Em Token name, escreva painel-loja.
  3. Em Expiration, escolha o prazo maior possível (ex.: No expiration ou 1 ano).
  4. Em Repository access, marque Only select repositories e escolha mcinformatica.
  5. Em Permissions → Repository permissions, procure Contents e mude para Read and write.
  6. Clique em Generate token e copie o código que aparecer (começa com github_pat_).
  7. Volte aqui, cole o código no campo acima e clique em Entrar.

Guarde essa chave num lugar seguro. Ela fica salva só neste navegador — use o painel no seu computador ou celular pessoal, e clique em “Sair” se usar um aparelho compartilhado.
